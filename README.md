# Portfólio · Pedro Jefte

Meu site pessoal, feito com **HTML, CSS e JavaScript puro** e publicado no **GitHub Pages**.

🔗 **Acesse:** https://pedrojefte.github.io/

## O que tem

- Apresentação, projetos, sobre e contato em uma página
- Projetos em cartões no formato de ingresso de cinema, um aceno ao meu primeiro projeto, o CineVibe
- Botão para baixar o currículo em PDF
- Tema claro e escuro automático, conforme o celular ou computador
- Layout responsivo, navegação por teclado e link para pular direto ao conteúdo
- Prévia com imagem quando o link é compartilhado no LinkedIn e no WhatsApp

## Estrutura

```
index.html                 # todo o conteúdo da página
style.css                  # cores e fontes ficam no topo, em :root
script.js                  # ano automático no rodapé
curriculo-pedro-jefte.pdf  # currículo para download
img/                       # print dos projetos, imagem de prévia e ícone
```

## Como adicionar um projeto

Em `index.html`, copie um bloco `<article class="ingresso">` inteiro, troque os textos e links, e coloque o print do projeto em `img/`.

## Rodar localmente

Abra o `index.html` no navegador ou use a extensão Live Server do VS Code.
